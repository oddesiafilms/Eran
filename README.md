# Eran

An original medieval fantasy RPG in the Erde Rhelm universe, built for Android using Godot 4.

## Status
Early **greybox prototype** only: placeholder terrain, trees, fortress shapes, player capsule, third-person camera, and experimental touchscreen movement. No finished art, combat, quests, or animations yet.

## Run
Open `project.godot` in Godot 4.3 or newer and press Run. Android export is **not configured** yet; an Android SDK and export template will be needed to build an APK.

## Direction
Beautiful but mysterious medieval landscapes inspired by the atmosphere of dark fantasy RPGs, with an original world and characters. Eran starts with Kinetic and Spirit magic; the Life Power reveal comes later.
